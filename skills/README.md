# Skills

Skills are grouped by provenance, not by topic:

| Bucket | Meaning |
|--------|---------|
| [`mine/`](mine/) | Skills authored from scratch in this repository. |
| [`curated/`](curated/) | Community skills adapted to a personal workflow. Record what changed and why. |
| [`community/`](community/) | Skills copied verbatim from the community. Keep the upstream license and attribution; upgrade by re-copying upstream. |

Each bucket contains one folder per skill with a `SKILL.md` at its root. Skills
with scripts, references, or templates keep them inside the skill folder so a
skill stays a single copyable unit.

Installation: `npx github:feliperun/skills` (see the root `README.md`).
